# 🏠 HomeMart – Furniture & Decor

> A premium, responsive furniture and home décor e-commerce website built as an internship project.

[🌐 Live Demo](https://home-mart-furniture-decor.vercel.app/) • [▶️ Video Demonstration](https://youtu.be/_1KYu8BbJ40) • [📄 Internship Report](./HomeMart_Internship_Report.pdf)

---

## 📌 Project Overview

**HomeMart – Furniture & Decor** is a modern furniture and home décor e-commerce website designed with a warm, premium showroom aesthetic.

The website provides a complete customer journey — from discovering furniture collections and viewing detailed product information to managing a shopping cart and completing the checkout process.

The project was developed as part of a **Web Development / UI/UX & Frontend Development internship project**.

---

## 🎯 Objective

The main objective of HomeMart is to create a warm, premium and user-friendly online furniture shopping experience that reflects an artisanal furniture brand while providing practical e-commerce functionality.

The project focuses on:

- Product discovery
- Category-based browsing
- Detailed product information
- Cart management
- Wishlist functionality
- Checkout experience
- Responsive design
- Consistent premium visual identity

## 📱 Responsive Design

HomeMart is designed to provide a consistent experience across desktop, tablet and mobile devices.

The responsive layout adapts:

- Navigation
- Hero sections
- Product cards
- Category sections
- Product details
- Shopping cart
- Checkout forms
- Modals
- Content sections

The mobile experience is optimized for readability, usability and smooth navigation without horizontal overflow.
